Project Option: Recommendation UI

Frontend project paired with the backend Recommendation Engine.

PROJECT

Big Picture

A frontend recommendation UI exists to turn backend JSON into something a user can scan, filter and act on. It solves the problem of making data usable.

Visualization

User clicks interest
↓
React state updates
↓
Frontend calls /recommendations
↓
Loading state appears
↓
Cards render
↓
User gives feedback

Analogy

Storefront shelf: the backend chooses products from the warehouse, but frontend decides how the shelf looks, how filters work and what the shopper sees first.

Thinking Process

  1. I need to show recommendations.
  2. I need state for selected interest.
  3. I need loading and error states.
  4. I need a reusable card component.
  5. I need feedback buttons later.

Mini Assignment

Design the card data shape for one recommendation. Include id, title, tags and reason. Do not code the component yet.
