# DFS Patterns

DFS pattern assets:

- [__dfsdata.js](__dfsdata.js)
- [__dfseng.js](__dfseng.js)

Covered DFS patterns include basic recursive DFS, iterative DFS, connected components, flood fill, number of islands, max area, two-grid sub-islands, 8-directional DFS, boundary DFS, undirected cycle detection, directed cycle detection, bipartite coloring, topological sort, and all-paths backtracking.
