# Weighted & Greedy Graphs — Dijkstra · DSU · MST

Step-by-step animated revision hub for weighted/greedy graph patterns.

- **Dijkstra** — single-source shortest path (min-heap + relaxation)
- **Disjoint Set Union** — union by rank + path compression
- **Kruskal's MST** — sort edges + DSU cycle check
- **Prim's MST** — grow one tree via a min-heap

Each pattern: AlgoMaster-style notes (when / key insight / analogy / bugs / problems),
a frame-by-frame animation (heap, dist table, set forest, MST edges) synced to a live
code-trace highlight, and full **Striver (takeUforward) C++** with click-to-reveal comments.

Self-contained single file — no build, no external JS. Live at `/graphs/weighted-patterns/`.
